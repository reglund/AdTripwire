## Gate 8b

- A second rig publishes a day and the primary shows both: met with a simulated second rig
  (`friend-de`) on a local bare repository; not yet with a second machine and its own key.
- The second rig's key cannot change the root: enforced by the script only; GitHub deploy keys
  write the whole branch. Stated in `docs/rig-setup.md`.
- A person who has not seen the repository follows `docs/rig-setup.md` to a published row:
  **pending** until the first friend's rig is set up.

## Known limitations

- Trust is script discipline plus personal trust; a compromised rig can rewrite the dataset
  repository (never the code repository). Recovery: delete its key and its directory, republish.
- `data/trend.md` has no rig column (shared renderer with `exposure-trend.mjs`).
- Country and network are self-declared.
